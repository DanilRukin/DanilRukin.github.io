# Тензор

Реализовывать нашу нейросеть начнем с самого нуля - с тензора.

Вряд ли в моих статьях вы встретите академические определения. Нет, моя цель - донести все максимально понятно, на простом языке, ведь я точно также изучаю эту тему и сам пытаюсь во всем разобраться, и, как можно догадаться, я не очень то люблю заумные определения. Итак, тензор - это ни что иное, как многомерный массив.

Ну хорошо, он многомерный. Мы же тут собрались его реализовывать. Подумаем над типом данных этого массива. Пусть этот массив будет представлен типом `double`.

А как мы реализуем многомерность? Вообще, для нашей задачи - реализации LeNet хватит и обычной матрицы `double[][]` либо `double[,]`, но это не универсально от слова совсем. Нам понадобятся и массивы ранга 3, и больше. Поэтому, пусть данные тензора лежат в _одномерном_ массиве, а многомерность мы реализуем при помощи динамического вычисления индекса.

Итак, начнем:

```csharp
namespace SharpLeNet.Core;

/// <summary>
/// Тензор
/// </summary>
public class Tensor
{
    /// <summary>
    /// Основные данные
    /// </summary>
    public double[] Data { get; private set; }

    /// <summary>
    /// Форма тензора (размерности по каждому измерению)
    /// </summary>
    public int[] Shape { get; private set; }

    /// <summary>
    /// Набор смещений по каждому измерению
    /// </summary>
    /// <remarks>
    /// Strides[i] показывает, насколько элементов надо сместиться в
    /// <see cref="Data"/> при увеличении i-го индекса на 1
    /// </remarks>
    public int[] Strides { get; private set; }

    /// <summary>
    /// Общее кол-во элементов. Произведение всех размерностей.
    /// </summary>
    public int Size => Data.Length;

    /// <summary>
    /// Ранг - количество измерений.
    /// </summary>
    public int Rank => Shape.Length;
}

```

Основные данные будут лежать в массиве `Data`, также будем хранить размерности нашего массива в свойстве `Shape`, например, занчение в `Shape[0]` будет сообщать нам о том, сколько элементов находится в строке 0 массива `Data`. Реализуем также просты свойства `Size` (общее количество элементов в тензоре) и `Rank` (ранг тензора, т.е. его количество измерений).

Что за свойство `Strides`? - спросите вы. Здесь я напомню об арифметике указателей. Как известно, в С++ массив можно представить в виде указателя, а затем уже выделить память для него. Массив - это всегда непрерывная область памяти, заданного размера, а его имя - это адрес начала первого элемента в массиве (с индексом 0). Вообще, массив любого ранга можно представить в виде одномерного, но работать с ним, как с многомерным. Например, если мы работаем с матрицей, то как нам использовать для этого одномерный массив?

В памяти матрица точно также представлена одномерным массивом, а компилятор облегчает нам работу с ней, используя индексы, заданные в `[x][y]` для вычисления реального положения элемента в одномерном массиве в памяти. Делает он это следующим образом:

`index = (x*(кол-во столбцов) + y)*i`, где `i` размер типа данных массива в байтах, например, если массив типа `int`, то `i = 4`. Т.е., если мы хотим получить элемент 1 в строке 2, то надо пропустить 2 блока размера `y` и от этого положения взять элемент 1 (не 0, потому что индексация с нуля).
Возьмем эту идею для наших вычислений. Мы будем работать с многомерным массивом, как одномерным, но использовать смещения для вычисления реального положения нужного элемента.

Вычислять такое смещение каждый раз при обращении к тензору по индексу очень затратно. Однако, мы можем вычислить эти смещения уже на этапе создания тензора, а затем использовать вычисленные константы. Реализуем вычисление смещений:

```csharp
/// <summary>
/// Вычисление страйдов
/// </summary>
private void ComputeStrides()
{
    Strides = new int[Rank];
    if (Rank == 0)
        return;

    Strides[Rank - 1] = 1;
    for (int i = Rank - 2; i >= 0; i--)
    {
        // Каждый следующий страйд умножаем на размер следующего измерения
        Strides[i] = Strides[i + 1] * Shape[i + 1];
    }
}
```

Почему начинаем с конца и почему последний элемент всегда = 1?

Рассмотрим тензор формы `[2, 3, 4]` (ранг 3):

Линейный массив: `Data[24]` (2×3×4=24 элементов)

Индексация: `tensor[i, j, k]` где:

- `i` от 0 до 1 (первое измерение, размер 2)
- `j` от 0 до 2 (второе измерение, размер 3)
- `k` от 0 до 3 (третье измерение, размер 4)

Формула индекса: `index = i * stride_i + j * stride_j + k * stride_k`

Вычисляем страйды с конца:

Для измерения `k`: если увеличить `k` на 1, мы переходим к следующему элементу → `stride_k = 1`

Для измерения `j`: чтобы перейти к следующему `j` при том же `i`, нужно пропустить целую строку размером 4 элемента → `stride_j = 4`

Для измерения `i`: чтобы перейти к следующему `i`, нужно пропустить целую матрицу `3×4=12` элементов → `stride_i = 12`

Итого: `Strides = [12, 4, 1]`

Проверка:

- `tensor[0, 1, 2] = 0*12 + 1*4 + 2*1 = 6` (7-й элемент, начиная с 0)
- `tensor[1, 2, 3] = 1*12 + 2*4 + 3*1 = 23` (последний элемент)

Итак, мы вычислил смещения. Теперь можно использовать их для вычисления положения реального индекса элемента в `Data`. Для этого, реализуем индексатор:

```csharp
public double this[params int[] indices]
{
    get
    {
        int index = CalculateOneDimensionIndexFromManyDimensionIndices(indices);
        return Data[index];
    }
    set
    {
        int index = CalculateOneDimensionIndexFromManyDimensionIndices(indices);
        Data[index] = value;
    }
}

/// <summary>
/// Вычисляет итоговый индекс в одномерном массиве <see cref="Data"/>, исходя
/// из переданных многомерных индексов
/// </summary>
/// <param name="indices">Индексы в каждом измерении</param>
/// <exception cref="ArgumentException"></exception>
/// <exception cref="IndexOutOfRangeException"></exception>
private int CalculateOneDimensionIndexFromManyDimensionIndices(params int[] indices)
{
    if (indices.Length != Rank)
        throw new ArgumentException($"Количество индексов должно совпадать к рангом тензора." +
            $" Индексов получено = {indices.Length}. Ожидалось = {Rank}");
    int index = 0;
    for (int i = 0; i < indices.Length; i++)
    {
        if (indices[i] >= Shape[i])
            throw new IndexOutOfRangeException($"Индекс {indices[i]} превышает " +
                $"размерность измерения {i}. Размерность = {Shape[i]}");
        index += indices[i] * Strides[i];
    }
    return index;
}
```

Все очень просто - мы берем заданный индекс и умножаем его на соответствующее смещение, получая необходимое смещение в массиве `Data`.

Теперь можно реализовать операции изменения размерности тензора (Reshape) и транспонирование (только для матриц).

```csharp
// Изменяет форму тензора
/// </summary>
/// <param name="newShape">Новые размерности</param>
public Tensor Reshape(params int[] newShape)
{
    int newTensorSize = newShape.Aggregate(1, (a, b) => a * b);
    if (Size != newTensorSize)
        throw new ArgumentException($"Новая размерность тензора не соответствует" +
            $" предыдущей размерности!. Новая размерность = {newTensorSize}. " +
            $"Предыдущая размерность = {Size}");
    return new Tensor(Data, newShape);
}

/// <summary>
/// Транспонирование тензора (для матрицы)
/// </summary>
public Tensor Transpose()
{
    if (Rank != 2)
        throw new InvalidOperationException("Транспонирование поддерживается только для 2D тензоров (матриц)");
    Tensor transposed = new Tensor([Shape[1], Shape[0]]); // меням местами размерности
    for (int i = 0; i < Shape[0]; i++)
    {
        for (int j = 0; j < Shape[1]; j++)
        {
            transposed[j, i] = this[i, j]; // столбцы transposed заполняем строками текущего экземпляра
        }
    }
    return transposed;
}
```

Вопрос к вам - безопасен ли такой Reshape? Вообще, нет.

Reshape может работать без копирования только если новый тензор можно обойти с постоянными страйдами. В NumPy/PyTorch есть понятие "contiguous" тензора.

_Правило_: Reshape без копирования возможен, если при обходе данных в новом порядке мы движемся по возрастающим адресам в Data. У нас Reshape работает без копирования благодаря тому, что обход массива осуществляется по строкам.

Осталось реализовать несколько вспомогательных и довольно полезных методов - клонирование, заполнение тензора значениями, создание тензора из нулей/единиц:

```csharp
/// <summary>
/// Клонирует тензор (глубокое копирование)
/// </summary>
public Tensor Clone()
{
    return new Tensor((double[])Data.Clone(), (int[])Shape.Clone());
}

/// <summary>
/// Заполняет тензор значениями
/// </summary>
/// <param name="value">Значение, которым будет заполнен весь тензор</param>
public void Fill(double value)
{
    for (int i = 0; i < Size; i++)
    {
        Data[i] = value;
    }
}

/// <summary>
/// Создает тензор, инициализированный нулями
/// </summary>
/// <param name="shape">Размерности тензора</param>
public static Tensor Zeros(params int[] shape) => new Tensor(shape);

/// <summary>
/// Создает тензор, инициализированный единицами
/// </summary>
/// <param name="shape">Размерности тензора</param>
public static Tensor Ones(params int[] shape)
{
    Tensor result = new Tensor(shape);
    result.Fill(1.0);
    return result;
}
```
